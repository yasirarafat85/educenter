## ৩. সব ফিচার (কী কী করা যায়)

### মূল নোট
- নোট/স্নিপেট সেভ করে **এক ট্যাপে কপি** (কপি-কাউন্ট গোনা হয়)
- শিরোনাম + বডি (খালি শিরোনাম চলে)
- **নোটে ট্যাপ → বিস্তারিত ভিউ** (v1.3) — পুরো লেখা দেখা, সিলেক্ট/কপি, Edit/Share
- **Favorites** (স্টার) — আলাদা লিস্ট
- **Pin to top** — গুরুত্বপূর্ণ নোট উপরে
- **সার্চ** — শিরোনাম/বডিতে
- **সর্ট** — Recent / A–Z / Most copied
- **নোটের রঙ** — কালার স্ট্রিপ
- **চেকলিস্ট** — প্রতি লাইন একটা টিক-যোগ্য আইটেম
- **শেয়ার** — অন্য অ্যাপে টেক্সট পাঠানো
- **হোম-স্ক্রিন উইজেট** — নোট লিস্ট

### ক্যাটাগরি
- নোট ভাগ করা, ক্যাটাগরি অনুযায়ী ফিল্টার
- ক্যাটাগরির ভেতরে নতুন নোট বানালে **অটো সেই ক্যাটাগরিতে যায়** (v1.3)

### রিমাইন্ডার
- নোটে তারিখ+সময় সেট → নোটিফিকেশন (সাউন্ড+ভাইব্রেশন)
- **এখন ঠিক সময়ে বাজে** (v1.3) — `setAlarmClock()` দিয়ে Doze থেকেও

### লক (নিরাপত্তা)
- মাস্টার পাসওয়ার্ড → **per-note লক**
- লক টাইমার: Off / **Immediate** / 10s / 30s / 1 min / 5 min / Manual
- **ফিঙ্গারপ্রিন্ট আনলক** (বায়োমেট্রিক)
- লক করা নোটের **নাম দেখা যায় কিন্তু ভেতরের লেখা লুকানো** থাকে, কপি/ডিলিটও আটকানো

### থিম
- Light / Dark
- পাসওয়ার্ড ফিল্ডে 👁 show/hide বাটন

### ব্যাকআপ / রিস্টোর
- **On this phone (automatic)** — পাথ/ফাইল ছাড়াই অ্যাপ-স্টোরেজে, প্রতিটা পরিবর্তনে **সাথে সাথে** সেভ, এক ট্যাপে রিস্টোর
- **Back up now** বাটন — চাইলে ম্যানুয়ালি সেভ
- **Cloud backup (optional)** — Google Drive/ফাইলে অতিরিক্ত কপি
- **Uninstall-এ অটো রিস্টোর** — একই Google অ্যাকাউন্টে রিইনস্টলে নোট ফেরে
- খালি ব্যাকআপে রিস্টোর করলে নোট **মুছে যায় না** (নিরাপত্তা গার্ড)

### v1.3-এর ৫টা বাগ ফিক্স (৮ আগস্ট ২০২৬)

1. **নোটে ট্যাপ → বিস্তারিত ভিউ**
   *সমস্যা:* ট্যাপ করলে সরাসরি কপি হতো, পুরো লেখা দেখতে এডিটে যেতে হতো।
   *সমাধান:* নতুন read-only "Note details" স্ক্রিন — ট্যাপে পুরো লেখা, নিচে Copy বাটন।

2. **ক্যাটাগরিতে নতুন নোট খালি দেখাত**
   *সমস্যা:* ক্যাটাগরি খুলে নতুন নোট বানালে সেটা কোনো ক্যাটাগরিতে assign হতো না, তাই ক্যাটাগরিতে দেখা যেত না / খালি মনে হতো।
   *সমাধান:* নতুন নোটে চলতি ক্যাটাগরি অটো-সিলেক্ট।

3. **Back বাটন ছিল না**
   *সমস্যা:* সব সেকেন্ডারি পেজে শুধু হ্যামবার্গার মেনু, সব সাইডবার থেকে করতে হতো।
   *সমাধান:* Categories/Reminders/Trash/Settings ও ক্যাটাগরি-ভিউতে **← ব্যাক অ্যারো**।

4. **রিমাইন্ডার ২-৩ মিনিট দেরি**
   *সমস্যা:* exact-alarm permission না থাকায় inexact alarm ব্যবহার হতো, যেটা Doze-এ ব্যাচ হয়ে দেরিতে বাজত।
   *সমাধান:* `AlarmManager.setAlarmClock()` — এটা সবসময় exact, Doze থেকেও জাগে, আর **কোনো special permission লাগে না** (Play-safe)।

5. **কিছু ডিভাইসে ডিলিট Trash-এ যেত না**
   *সমস্যা:* full-object `@Update` — স্মৃতিতে থাকা পুরনো (stale) নোট-কপি দিয়ে আপডেট হওয়ায় কিছু ডিভাইসে গোলমাল।
   *সমাধান:* id দিয়ে **atomic `UPDATE ... WHERE id`** কোয়েরি — সব ডিভাইসে নিশ্চিত।

## ৫. ⭐ ব্যাকআপ/রিস্টোরের সমস্যা কেন বারবার হচ্ছিল (বিস্তারিত)

এটা সবচেয়ে বেশি ঝামেলা দিয়েছে, তাই আলাদা করে বুঝিয়ে রাখছি। মূলত **তিনটা আলাদা কারণ** পরপর ধরা পড়েছিল — একটা ঠিক করলে পরেরটা সামনে আসত, তাই মনে হচ্ছিল "বারবার হচ্ছে"।

### কারণ ১ — ব্যাকআপ বাসি (stale) ছিল
আগে ব্যাকআপ **debounce** করা হতো: কোনো পরিবর্তনের ২.৫ সেকেন্ড পর সেভ হতো। কিন্তু ইউজার নোট বানিয়ে/ডিলিট করে সাথে সাথে রিস্টোর চাপলে, সর্বশেষ নোটগুলো তখনো ব্যাকআপে যায়নি — ফলে **পুরনো (যেমন ৯-নোটের) ব্যাকআপ** রিস্টোর হতো। তাই সংখ্যা মিলত না ("৪-৫ বানিয়েছি কিন্তু ৯ দেখাচ্ছে")।
- ✅ **ফিক্স:** লোকাল ব্যাকআপ এখন প্রতিটা পরিবর্তনে **সাথে সাথে** লেখা হয় (debounce বাদ)। ক্লাউড কপি শুধু debounced।

### কারণ ২ — রিস্টোরের পর নোট দেখা যেত না
রিস্টোরে "Restored 9 note(s)" দেখাত কিন্তু All Notes-এ কিছুই আসত না। দুইটা উপ-কারণ:
- **(ক) DB transaction:** রিস্টোর একটা `withTransaction {}`-এর ভেতরে delete+insert করত। কিছু ক্ষেত্রে এতে লিস্টের Flow ঠিকমতো রিফ্রেশ হতো না।
- **(খ) Trash অবস্থা:** রিস্টোর করা নোটের পুরনো `isTrashed` মান রাখা হতো — তাই আগে ট্র্যাশে থাকা নোট রিস্টোরের পরও ট্র্যাশেই থেকে যেত, All Notes-এ দেখা যেত না।
- ✅ **ফিক্স:** (ক) `withTransaction` বাদ, প্রমাণিত sequential delete+insert (লিস্ট ঠিকমতো রিফ্রেশ করে)। (খ) রিস্টোরে সব নোট **`isTrashed = false`** করে দৃশ্যমান আনা হয়।

### কারণ ৩ — ক্লাউড অ্যাক্সেস হারিয়ে যেত
"Backup failed" আসত (গুগল প্লে কোনো এরর দিত না — এটা অ্যাপের ভেতরের)। রিইনস্টল/ফাইল সরানোর পর আগে বেছে নেওয়া ক্লাউড ফাইলের SAF permission হারিয়ে যেত, কিন্তু অ্যাপ পুরনো লিংক ধরে রাখত।
- ✅ **ফিক্স:** অ্যাক্সেস হারালে পুরনো কনফিগ নিজে থেকে ক্লিয়ার হয়, বার্তা দেখায় "Cloud file access was lost — set it up again"; আর `writeBackup` স্ট্রিম null হলে false ফেরে।

### এখন নিয়মটা মনে রাখুন (টেস্ট করার সময়)
1. নোট বানান/বদলান → (চাইলে **Back up now**) → 2. একটা ডিলিট + একটা যোগ করুন → 3. **Restore** → সঠিক সংখ্যা + All Notes-এ নোটগুলো আসবে।
খালি অবস্থায় রিস্টোর করলে বার্তা: *"Backup is empty — your notes are unchanged"* (নোট মুছবে না)।

## ৭. বিল্ড ও ডিপ্লয় (কীভাবে অ্যাপ তৈরি হয়)

- **বিল্ড শুধু GitHub Actions-এ** (`.github/workflows/android-clipnotes.yml`) — কম্পিউটারে কিছু ইনস্টল লাগে না (লোকালে `dl.google.com` ব্লক)।
- প্রতিটা push-এ: **debug APK** (সবসময়) + **signed AAB** (GitHub Secrets থাকলে)।
- Secrets: `CLIPNOTES_KEYSTORE_BASE64`, `CLIPNOTES_KEYSTORE_PASSWORD`, `CLIPNOTES_KEY_ALIAS`, `CLIPNOTES_KEY_PASSWORD` (সেট করা আছে)।
- বিল্ড হলে run পেজের **Artifacts → `clipnotes-release-aab`** থেকে AAB নামিয়ে Play-তে আপলোড।
- 🔴 **Signing key কখনো হারাবেন না** — একই key দিয়েই সব আপডেট সাইন হতে হয় (স্ক্র্যাচপ্যাডে keystore + পাসওয়ার্ড ব্যাকআপ রাখা)।

## ৮. ✅ কী কী খেয়াল রাখতে হবে (চেকলিস্ট)

প্রতিটা নতুন আপডেটের আগে/পরে:

- [ ] `versionCode` **বাড়িয়েছি?** (Play-র সবচেয়ে কমন এরর এখানেই)
- [ ] দরকারে `versionName`-ও বাড়িয়েছি (যেমন 1.3)
- [ ] GitHub Actions বিল্ড **success** হয়েছে (debug APK + AAB দুটোই)?
- [ ] নতুন Room কলাম/টেবিল যোগ করলে **migration লিখেছি** (নাহলে পুরনো ইউজারের অ্যাপ ক্র্যাশ করবে)
- [ ] ভিজ্যুয়াল/UX পরিবর্তন **আসল ফোনে** টেস্ট করেছি (এমুলেটর/CI শুধু কম্পাইল যাচাই করে, দেখতে কেমন লাগে না)
- [ ] Play-তে AAB আপলোডের পর **"Send changes for review"** চেপেছি
- [ ] Data safety / privacy policy / rating ঠিক আছে (নতুন permission যোগ করলে বদলাতে হতে পারে)
- [ ] নতুন permission যোগ করার আগে ভেবেছি Play policy-তে সমস্যা হবে কিনা (যেমন exact-alarm ইচ্ছাকৃতভাবে এড়ানো হয়েছে)

### সাধারণ ভুল যা এড়াবেন
- ❌ একই versionCode দুইবার — Play নেয় না।
- ❌ শুধু AAB আপলোড করে "Send for review" না চাপা — আপডেট লাইভ হয় না।
- ❌ APK আপলোড করার চেষ্টা — Play-তে AAB লাগে (APK শুধু নিজের ফোনে টেস্টের জন্য)।
- ❌ signing key বদলে ফেলা — তাহলে আর আপডেট দেওয়া যাবে না।
- ❌ Room-এ কলাম যোগ করে migration না লেখা — পুরনো ইউজারের অ্যাপ ক্র্যাশ।
